# Provenance of the bundled reference data

Every table shipped with tidybrreg is listed here with its source,
licence, vintage, the transformations applied, and how the package uses
it. The tables are regenerated by `data-raw/build_dictionaries.R`; the
vintages below are the dates of the last regeneration that touched each
table, taken from the repository history.

## Exported datasets (`data/`)

- [field_dict](https://sondreskarsten.github.io/tidybrreg/reference/field_dict.md):

  **Package-authored.** A mapping from BRREG JSON paths to English
  column names and R types, written by the package author from the
  Enhetsregisteret API documentation
  (<https://data.brreg.no/enhetsregisteret/api/dokumentasjon/>) and from
  fields observed on live responses. The Norwegian paths are BRREG's
  identifiers; the English names and types are the author's editorial
  choices and carry the package's MIT licence. Last revised 2026-06-16.
  Used at runtime by every parser.

- [legal_forms](https://sondreskarsten.github.io/tidybrreg/reference/legal_forms.md):

  **BRREG code list plus manual translation.** `code`, `name_no` and
  `expired` are retrieved from
  `GET https://data.brreg.no/enhetsregisteret/api/organisasjonsformer`,
  published by the Brønnøysund Register Centre under the Norwegian
  Licence for Open Government Data (NLOD) 2.0
  (<https://data.norge.no/nlod/en/2.0>); `name_en` is a manual
  translation by the package author (unreviewed by BRREG), falling back
  to `name_no` for codes without a translation. Retrieved 2026-06-16.
  Used by
  [`brreg_label()`](https://sondreskarsten.github.io/tidybrreg/reference/brreg_label.md).

- [role_types](https://sondreskarsten.github.io/tidybrreg/reference/role_types.md):

  **Package-authored from BRREG documentation.** Codes and Norwegian
  descriptions follow the role codes listed in the Enhetsregisteret
  roller documentation and the Fullmakt service; English names are a
  manual translation by the package author. BRREG publishes no
  machine-readable role code list with translations. Last revised
  2026-06-16. Used by
  [`brreg_roles()`](https://sondreskarsten.github.io/tidybrreg/reference/brreg_roles.md),
  [`brreg_roles_legal()`](https://sondreskarsten.github.io/tidybrreg/reference/brreg_roles_legal.md),
  [`brreg_signatur()`](https://sondreskarsten.github.io/tidybrreg/reference/brreg_signatur.md),
  [`brreg_prokura()`](https://sondreskarsten.github.io/tidybrreg/reference/brreg_prokura.md)
  and
  [`brreg_label()`](https://sondreskarsten.github.io/tidybrreg/reference/brreg_label.md).

- [role_groups](https://sondreskarsten.github.io/tidybrreg/reference/role_groups.md):

  **Package-authored from BRREG documentation.** As
  [role_types](https://sondreskarsten.github.io/tidybrreg/reference/role_types.md),
  for role group (`rollegruppe`) codes. Last revised 2026-06-16. Used by
  [`brreg_roles()`](https://sondreskarsten.github.io/tidybrreg/reference/brreg_roles.md)
  and
  [`brreg_label()`](https://sondreskarsten.github.io/tidybrreg/reference/brreg_label.md).

- [regnskap_dict](https://sondreskarsten.github.io/tidybrreg/reference/regnskap_dict.md):

  **Package-authored.** As
  [field_dict](https://sondreskarsten.github.io/tidybrreg/reference/field_dict.md),
  for the Regnskapsregisteret filing: dot paths of the filing JSON
  (OpenAPI 1.1.16,
  <https://data.brreg.no/regnskapsregisteret/regnskap/v3/api-docs>,
  population-verified against the brreg-json-fetcher `data-2026-10`
  release) to English names and R types. Written 2026-10-30. Used by
  [`brreg_regnskap()`](https://sondreskarsten.github.io/tidybrreg/reference/brreg_regnskap.md).

- [regnskap_groups](https://sondreskarsten.github.io/tidybrreg/reference/regnskap_groups.md):

  **Package-authored.** The objects that group line items in the filing,
  with English and Norwegian names; the level-0 rows are the three
  statements. The Norwegian names are the presentation-plan captions of
  the Norwegian Accounting Act; English is a manual translation by the
  package author. Written 2026-10-30. Used by
  [`brreg_regnskap()`](https://sondreskarsten.github.io/tidybrreg/reference/brreg_regnskap.md)
  and
  [`brreg_label()`](https://sondreskarsten.github.io/tidybrreg/reference/brreg_label.md).

- [regnskap_items](https://sondreskarsten.github.io/tidybrreg/reference/regnskap_items.md):

  **Package-authored.** English and Norwegian labels of the line items
  named in
  [regnskap_dict](https://sondreskarsten.github.io/tidybrreg/reference/regnskap_dict.md),
  as
  [role_types](https://sondreskarsten.github.io/tidybrreg/reference/role_types.md)
  is for role codes. Written 2026-10-30. Used by
  [`brreg_label()`](https://sondreskarsten.github.io/tidybrreg/reference/brreg_label.md).

## Internal fallback dictionaries (`R/sysdata.rda`)

- `nace_codes`:

  **Statistics Norway (SSB) KLASS classification 6** (Standard
  Industrial Classification SN2007), English labels, retrieved from
  `https://data.ssb.no/api/klass/v1/classifications/6/codesAt` on
  2026-06-16 (the effective date of the codes is that retrieval date).
  SSB publishes KLASS classifications as open data under NLOD 2.0
  according to its data licence page
  (<https://www.ssb.no/en/omssb/tjenester-og-verktoy/api/klass-api>);
  the maintainer has not obtained a separate confirmation, so the
  statement is reproduced as published. Used only when SSB KLASS is
  unreachable or `source = "bundled"` is requested in
  [`get_brreg_dic()`](https://sondreskarsten.github.io/tidybrreg/reference/get_brreg_dic.md);
  the returned tibble carries `vintage`.

- `sector_codes`:

  **SSB KLASS classification 39** (institutional sector), English
  labels, same source, licence statement, retrieval date and use as
  `nace_codes`.

## Register data

Entity, role, group, signature and update data retrieved at runtime come
from the Brønnøysund Register Centre's open APIs and are licensed under
NLOD 2.0; the licence requires attribution to the Brønnøysund Register
Centre when the data are redistributed. KLASS labels retrieved at
runtime are Statistics Norway's.
